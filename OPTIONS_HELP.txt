View options:
    --fullscreen
        Display the app in full screen.

    --scale=...
        Set a scaling factor for the window. The default is no scale hack, which is equivalent to a value of 1.

    --screen-size=WIDTHxHEIGHT
        Set the emulated screen size. The default is 240x320.

Font options:
    --font-size-override=small|medium|big
        Override the font size used for Mythroad text rendering.

CPU options:
    --cpu=dynarmic|interpreter
        Select the CPU backend. The default is dynarmic.
